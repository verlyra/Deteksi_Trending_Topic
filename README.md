<h2 align="center">📈 Deteksi Trending Topik — Text Processing & TF-IDF</h2>
<p align="center">Project tugas Mata Kuliah <b>Deteksi Trending Topik</b><br/>Menggunakan Python, TF-IDF, dan Data Berita/Media Sosial untuk analisis topik populer.</p>

---

## 🌟 Deskripsi Singkat
Proyek ini menerapkan metode **TF-IDF (Term Frequency – Inverse Document Frequency)** untuk menghitung tingkat kepentingan kata kunci dalam kumpulan dokumen, kemudian mengidentifikasi kata yang memiliki bobot tertinggi sebagai **topik yang sedang trending** 📊.

Dataset berupa kumpulan teks (berita, artikel, atau postingan media sosial), diolah melalui beberapa tahapan pembersihan data dan analisis frekuensi kata.

---

## 🧠 Fitur Utama
- 🔤 Preprocessing teks (case folding, tokenizing, stopword removal, stemming)
- 📊 Perhitungan bobot TF-IDF setiap kata
- 🏷 Identifikasi kata dengan bobot tertinggi sebagai *top trending keywords*
- 🧹 Cleaning otomatis untuk mengurangi noise pada data
- 💾 Penyimpanan hasil ke database / file CSV
